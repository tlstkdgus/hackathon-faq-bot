# 해커톤 FAQ 디스코드 봇 🦁

학생들이 자주 묻는 질문에 **`/해커톤질문`** 슬래시 커맨드로 답해주는 FAQ 봇입니다.
키워드 매칭으로 대부분 무료로 답하고, 확실히 못 잡은 질문만 Claude에게 넘겨 자연어로 답합니다.
질문과 답변은 **물어본 사람에게만** 보입니다 (다른 사람들에게 공개 노출 안 됨).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `bot.py` | 봇 본체 (실행 파일) |
| `faq_engine.py` | `faq.md`를 읽고 키워드 매칭하는 로직 (discord 의존성 없음) |
| `faq.md` | **질문/답변 데이터 — 여러분이 수정할 파일!** |
| `claude_engine.py` | Claude Haiku로 자연어 답변 생성 (키워드 매칭 실패 시 폴백) |
| `llm.py` | 어떤 LLM을 쓸지 고르는 스위치 (`LLM_PROVIDER` 환경변수, 현재 claude만 구현) |
| `stats_engine.py` | 질문 사용 기록/집계 로직 (discord 의존성 없음) |
| `stats_cli.py` | 터미널에서 바로 통계 확인 (`python stats_cli.py`) |
| `hours.py` | 질문 운영시간 판단 로직 (discord 의존성 없음) |
| `requirements.txt` | 필요한 패키지 목록 |
| `.env.example` | 환경변수 템플릿 (복사해서 `.env`로 사용) |

## 1. 디스코드 봇 만들기 (개발자 포털)

1. https://discord.com/developers/applications 접속 → **New Application** 클릭, 이름 입력 (예: `해커톤도우미`)
2. 왼쪽 메뉴 **Bot** 탭으로 이동
3. **Privileged Gateway Intents** 에서 ✅ **MESSAGE CONTENT INTENT** 를 반드시 켜주세요 (안 켜면 봇이 메시지를 못 읽어요)
4. **Reset Token** 을 눌러 토큰을 복사해 둡니다 (⚠️ 절대 깃허브 등에 올리지 마세요!)

## 2. 봇을 서버에 초대하기

슬래시 커맨드(`/해커톤질문` 등)를 쓰려면 `bot` 스코프뿐 아니라 **`applications.commands`** 도 필요합니다.

1. 왼쪽 메뉴 **OAuth2 → URL Generator**
2. SCOPES에서 `bot` **과** `applications.commands` 둘 다 체크
3. BOT PERMISSIONS에서 `Send Messages`, `Read Message History` 체크
4. 아래 생성된 URL을 브라우저에 붙여넣고 → 해커톤 서버 선택 → 승인

이미 `bot` 스코프만으로 초대했다면, 위 방식으로 **다시 승인**하면 됩니다 (봇이 빠지거나 초기화되지 않고 권한만 추가됨).

## 3. 실행하기

Python 3.9 이상이 필요합니다.

```bash
python -m pip install -r requirements.txt

# .env.example을 .env로 복사한 뒤 값을 채워주세요
copy .env.example .env   # Windows
# cp .env.example .env   # Mac/Linux

python bot.py
```

`.env`에 채울 항목:

| 변수 | 필수 | 설명 |
|---|---|---|
| `DISCORD_TOKEN` | ✅ | 1번에서 발급받은 봇 토큰 |
| `DISCORD_GUILD_ID` | 권장 | 서버 ID. 설정하면 슬래시 커맨드가 **즉시** 반영됨 (안 하면 최대 1시간). 디스코드 설정 → 고급 → 개발자 모드 켠 뒤 서버 아이콘 우클릭 → ID 복사 |
| `ANTHROPIC_API_KEY` | 선택 | Claude 자연어 폴백을 쓰려면 필요 ([console.anthropic.com](https://console.anthropic.com) → API Keys). 비워두면 키워드 매칭만 동작 |
| `LLM_PROVIDER` | 선택 | 기본 `claude`. 지금은 claude만 구현됨 |
| `QA_START_HOUR` / `QA_END_HOUR` | 선택 | 질문 답변 운영시간 (한국시간, 24시간제). 기본 10~18시. 하루 종일 받으려면 `0`과 `24` |

⚠️ `.env` 파일은 `.gitignore`에 포함되어 있어 git에 커밋되지 않습니다. 그래도 실수로 `git add .env`를 하지 않도록 주의하세요.

터미널에 아래처럼 뜨면 성공:
```
✅ 로그인 성공: ... (FAQ 49개 로드, 답변 모드: 키워드 + claude 폴백)
   질문 운영시간: 매일 10:00~18:00 (KST)
```

## 4. 사용법 (학생들에게 공지할 내용)

질문은 **슬래시 커맨드로만** 받습니다 (`!질문`, 봇 멘션 등은 답 대신 사용법 안내만 나감).

- **`/해커톤질문 <내용>`** — 🔒 질문·답변이 **나에게만** 보임. 예: `/해커톤질문 sjf 트랙 심사기준이 뭐예요?`
- **`/해커톤주제`** — 🔒 답할 수 있는 주제를 카테고리별로 정리해서 목록으로 보여줌
- **`/해커톤도움`** — 🔒 사용법 안내
- **`/해커톤통계`** — 🔒 (서버 관리 권한자만) 총 질문 수·인기 주제 등 사용 통계
- **`!리로드`** — faq.md 수정 후 다시 불러오기 (서버 관리 권한 필요, 유일하게 남은 `!` 명령)

질문은 **운영시간(기본 매일 10:00~18:00, 한국시간)에만** 답변됩니다. 그 외 시간엔 "운영시간이 아니에요" 라고만 안내합니다.

## 5. 노션 내용 넣는 법 ⭐

`faq.md`를 열어 아래 형식으로 추가하면 끝입니다.

```
## 주제이름 | 키워드1, 키워드2, 키워드3
답변 내용 (노션에서 복사해서 붙여넣기 OK, 여러 줄 가능)
```

- 노션에서 페이지 내용을 복사해 답변 부분에 붙여넣으세요.
  (노션 우측 상단 ⋯ → **Export → Markdown** 으로 내보내면 서식까지 그대로 가져올 수 있어요)
- **키워드는 학생들이 실제로 쓸 법한 단어**로 다양하게 넣을수록 잘 잡힙니다.
  예: `와이파이, wifi, 인터넷, 비번, 비밀번호`
- 수정한 뒤 디스코드에서 `!리로드` 를 입력하면 봇 재시작 없이 바로 반영됩니다.

**주제가 많아지면** `# 카테고리 이름` (해시 1개)으로 구획을 나눌 수 있습니다. 매칭/답변 내용엔 전혀 영향이 없고, VS Code 아웃라인·미리보기 및 `/해커톤주제` 목록에서 카테고리별로 묶어서 보여주는 용도로만 쓰입니다.

```
# 팀 & 트랙

## 팀 빌딩 | 팀, 팀원, ...
...

## 트랙 선택 | 트랙, ...
...
```

## 6. 사용 통계 확인하기

두 가지 방법 중 편한 대로 쓰세요:

- **디스코드에서**: `/해커톤통계` (서버 관리 권한자만 볼 수 있음)
- **로컬 터미널에서**: 봇을 안 켜도, 같은 폴더에서
  ```bash
  python stats_cli.py
  ```
  총 질문 수, 순 사용자 수, 키워드/LLM/실패 비율, 인기 주제 TOP5를 보여줍니다.

키워드로 못 잡은 질문은 `unanswered.log`에 실제 질문 텍스트로 남습니다 — 이 파일을 보면서 자주 나오는 표현을 `faq.md` 키워드에 추가하면 봇이 점점 똑똑해집니다.

두 로그 파일(`stats.log`, `unanswered.log`)은 학생 데이터가 담기므로 `.gitignore`에 포함되어 커밋되지 않습니다.

## 7. 계속 켜두려면 (호스팅)

봇은 `python bot.py`가 실행 중일 때만 작동합니다.

- **행사 당일만 쓴다면**: 운영진 노트북에서 그냥 켜두는 게 제일 간단해요.
- **24시간 돌리려면**: Railway, Fly.io 같은 서비스나 AWS/GCP 무료 티어 서버에 올리면 됩니다.
  - 배포 시 `.env` 대신 해당 서비스의 **환경변수(Variables)** 설정 화면에 같은 값들을 넣어야 합니다.
  - `stats.log`, `unanswered.log`를 계속 누적하려면, 디스크가 재배포마다 초기화되는 서비스라면 **영구 저장소(Volume)** 를 붙여야 합니다.

## 자주 묻는 문제

- **봇이 아무 반응이 없어요** → MESSAGE CONTENT INTENT를 켰는지, 봇에게 채널 읽기/쓰기 권한이 있는지 확인
- **`/해커톤질문`이 자동완성에 안 떠요** → `applications.commands` 스코프로 재초대했는지, `.env`에 `DISCORD_GUILD_ID`를 넣었는지 확인 (안 넣으면 반영에 최대 1시간)
- **`DISCORD_TOKEN 환경변수가 없습니다`** → 위 3번의 토큰 설정을 다시 확인
- **`pip install` 이 안 먹혀요 (Windows)** → `pip` 대신 `python -m pip install -r requirements.txt` 사용
- **질문을 못 알아들어요** → 해당 주제의 키워드에 그 표현을 추가하고 `!리로드` (또는 `unanswered.log` 확인)
- **`.env`를 고쳤는데 반영이 안 돼요** → 봇을 재시작해야 합니다 (`Ctrl+C` 후 `python bot.py`). `.env`는 시작할 때 한 번만 읽습니다.
- **지금은 운영시간이 아니라고만 떠요** → 정상 동작입니다. `QA_START_HOUR`/`QA_END_HOUR`로 시간을 조정하세요.

## Claude API 연동 (구현됨)

키워드로 못 잡는 다양한 질문 표현에 Claude Haiku가 자연어로 답합니다.

- `.env`에 `ANTHROPIC_API_KEY`를 넣으면 자동으로 활성화됩니다 (없으면 키워드 매칭만 동작).
- 비용 절감을 위해 **키워드 매칭이 먼저** 시도되고, 확실히 못 찾은 질문만 Claude로 넘어갑니다.
- `faq.md` 전체를 컨텍스트로 넣고 프롬프트 캐싱을 적용해 비용을 더 아낍니다.
- Claude API 오류가 나도 봇은 죽지 않고 조용히 안내 메시지로 넘어갑니다.

## 나중에 다른 LLM(OpenAI 등)으로 바꾸고 싶다면

`llm.py`가 이미 스위치 구조로 되어 있습니다. `claude_engine.py`와 같은 인터페이스
(`is_enabled()`, `answer(question, entries)`)로 `openai_engine.py`를 만들고
`.env`에 `LLM_PROVIDER=openai`만 넣으면 됩니다. `bot.py`, `faq_engine.py` 등
나머지 코드는 손댈 필요가 없습니다.
