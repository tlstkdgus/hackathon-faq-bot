# 해커톤 FAQ 디스코드 봇 🦁

학생들이 자주 묻는 질문에 **`/해커톤질문`** 슬래시 커맨드로 답해주는 FAQ 봇입니다.

**어떻게 답하나요**

1. 먼저 `faq.md`의 **키워드 매칭**으로 찾습니다 — 즉시 응답, 비용 0원
2. 못 찾으면 **LLM(OpenAI 또는 Claude)** 이 FAQ 자료를 근거로 답합니다
3. LLM이 실패하면 다른 백엔드로 자동 전환, 그것도 안 되면 안내 메시지

자료에 없는 내용은 지어내지 않고 "운영진에게 문의해주세요"로 안내합니다.
질문과 답변은 **물어본 사람에게만** 보입니다 (공개 채팅에 노출되지 않음).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `faq.md` | **질문/답변 데이터 — 운영진이 수정할 파일!** (9개 카테고리 / 66개 항목) |
| `bot.py` | 봇 본체 (실행 파일) |
| `faq_engine.py` | `faq.md` 파싱 + 키워드 매칭 |
| `llm.py` | LLM 백엔드 스위치 + 백엔드 간 자동 폴백 + **공용 답변 규칙(프롬프트)** |
| `openai_engine.py` | OpenAI로 자연어 답변 생성 |
| `claude_engine.py` | Claude로 자연어 답변 생성 (동일 인터페이스) |
| `stats_engine.py` | 질문 사용 기록/집계 |
| `stats_cli.py` | 터미널에서 통계 확인 (`python stats_cli.py`) |
| `digest.py` | 미답변 질문 분석 → 운영진 일일 리포트 |
| `hours.py` | 질문 운영시간 판단 |
| `paths.py` | 파일 경로 중앙 관리 (절대경로라 서버에서도 안전) |
| `requirements.txt` | 필요한 패키지 목록 |
| `.env.example` | 환경변수 템플릿 (복사해서 `.env`로 사용) |
| `deploy/` | 서버 배포 세트 — [배포 가이드](deploy/DEPLOY.md) |

> `faq_engine` · `hours` · `stats_engine` · `digest` 는 discord 의존성이 없어
> 봇을 띄우지 않고도 단독으로 실행·테스트할 수 있습니다.

## 1. 디스코드 봇 만들기 (개발자 포털)

1. https://discord.com/developers/applications 접속 → **New Application** 클릭, 이름 입력 (예: `해커톤도우미`)
2. 왼쪽 메뉴 **Bot** 탭으로 이동
3. **Privileged Gateway Intents** 에서 ✅ **MESSAGE CONTENT INTENT** 를 반드시 켜주세요 (안 켜면 봇이 메시지를 못 읽어요)
4. **Reset Token** 을 눌러 토큰을 복사해 둡니다 (⚠️ 절대 깃허브 등에 올리지 마세요!)

## 2. 봇을 서버에 초대하기

슬래시 커맨드(`/해커톤질문` 등)를 쓰려면 `bot` 스코프뿐 아니라 **`applications.commands`** 도 필요합니다.

1. 왼쪽 메뉴 **OAuth2 → URL Generator**
2. SCOPES에서 `bot` **과** `applications.commands` 둘 다 체크
3. BOT PERMISSIONS에서 `Send Messages`, `Read Message History` 체크
4. 아래 생성된 URL을 브라우저에 붙여넣고 → 해커톤 서버 선택 → 승인

이미 `bot` 스코프만으로 초대했다면, 위 방식으로 **다시 승인**하면 됩니다 (봇이 빠지거나 초기화되지 않고 권한만 추가됨).

## 3. 실행하기

**Python 3.10 이상**이 필요합니다. (`python --version`으로 확인)

```bash
python -m pip install -r requirements.txt

# .env.example을 .env로 복사한 뒤 값을 채워주세요
copy .env.example .env   # Windows
# cp .env.example .env   # Mac/Linux

python bot.py
```

`.env`에 채울 항목:

| 변수 | 필수 | 설명 |
|---|---|---|
| `DISCORD_TOKEN` | ✅ | 1번에서 발급받은 봇 토큰 |
| `DISCORD_GUILD_ID` | 권장 | 서버 ID. 설정하면 슬래시 커맨드가 **즉시** 반영됨 (안 하면 최대 1시간). 디스코드 설정 → 고급 → 개발자 모드 켠 뒤 서버 아이콘 우클릭 → ID 복사 |
| `OPENAI_API_KEY` | 선택 | OpenAI 자연어 답변용 ([platform.openai.com](https://platform.openai.com/api-keys)) |
| `ANTHROPIC_API_KEY` | 선택 | Claude 자연어 답변용 ([console.anthropic.com](https://console.anthropic.com) → API Keys) |
| `LLM_PROVIDER` | 선택 | 주 백엔드 `openai` 또는 `claude` (코드 기본값은 `claude`, `.env.example`은 `openai`) |
| `LLM_FALLBACK` | 선택 | 주 백엔드 실패 시 넘어갈 백엔드. 비우면 폴백 안 함 |
| `OPENAI_MODEL` | 선택 | 기본 `gpt-5.6-luna` (비용 최적화 모델). [모델 목록](https://platform.openai.com/docs/models) |
| `OPENAI_REASONING` | 선택 | 추론 강도. 기본 `none` — FAQ 답변엔 추론이 불필요하고, 켜면 비용·지연만 늘어남 |
| `ANTHROPIC_MODEL` | 선택 | 기본 `claude-haiku-4-5` |
| `OPENAI_TIMEOUT` / `ANTHROPIC_TIMEOUT` | 선택 | 응답 대기 상한(초). 기본 `20` |
| `QA_START_HOUR` / `QA_END_HOUR` | 선택 | 질문 답변 운영시간 (한국시간, 24시간제). **기본 `0`~`24`(24시간 개방)**. 낮에만 받으려면 `10`과 `17`, **자정을 넘기는 `20`~`4`도 지원합니다** |
| `DATA_DIR` | 선택 | 로그 파일을 저장할 폴더. 비워두면 프로젝트 폴더에 쌓임 |
| `ALLOWED_CHANNEL_IDS` | 선택 | 학생용 명령을 받을 채널 ID. 쉼표로 여러 개. **비우면 모든 채널에서 동작** ([아래 참고](#질문-채널-제한하기)) |
| `DIGEST_CHANNEL_ID` | 선택 | 미답변 질문 일일 리포트를 보낼 **운영진 전용** 채널 ID. 비우면 기능 꺼짐 ([아래 참고](#미답변-질문-일일-리포트-자동)) |
| `DIGEST_HOUR` | 선택 | 리포트 발송 시각(한국시간). 기본 `9` |

**모델 선택 참고** — `OPENAI_MODEL` 기본값 `gpt-5.6-luna`는 비용 최적화 모델입니다. FAQ 답변은 주어진 자료에서 찾아 옮기는 작업이라 상위 모델과 품질 차이를 체감하기 어려운 반면 가격 차이는 큽니다.

| 모델 | 입력 / 출력 (per MTok) |
|---|---|
| `gpt-5.6-luna` | $0.20 / $1.20 ← 기본값 |
| `gpt-5.6-terra` | $2 / $12 |
| `gpt-5.6-sol` | $5 / $30 |

`OPENAI_REASONING`은 추론 강도(`none`~`max`)입니다. 추론 토큰은 출력 토큰과 같은 단가로 과금되고 응답도 느려지므로, 추론이 필요 없는 FAQ 용도에선 `none`이 맞습니다.

⚠️ `.env` 파일은 `.gitignore`에 포함되어 있어 git에 커밋되지 않습니다. 그래도 실수로 `git add .env`를 하지 않도록 주의하세요.

터미널에 아래처럼 뜨면 성공:
```
   /슬래시 커맨드 4개 동기화 완료
✅ 로그인 성공: ... (FAQ 66개 로드, 답변 모드: 키워드 + openai (실패 시 claude 폴백))
   질문 운영시간: 매일 24시간 언제나 (KST)
   FAQ 파일: /home/ubuntu/hackathon-faq-bot/faq.md
   로그 폴더: /home/ubuntu/hackathon-faq-bot
   미답변 리포트: 매일 9:00 (KST) → 채널 1234567890123456789
```

> `FAQ 0개 로드`라고 뜨면 `faq.md`를 못 읽은 것입니다. 형식(`## 주제 | 키워드`)을 확인하세요.
>
> `답변 모드: 키워드 전용`이면 API 키가 안 읽힌 것입니다. 봇은 정상 작동하지만
> 키워드에 없는 표현은 답하지 못합니다.

## 4. 사용법 (학생들에게 공지할 내용)

질문은 **슬래시 커맨드로만** 받습니다 (`!질문`, 봇 멘션 등은 답 대신 사용법 안내만 나감).

- **`/해커톤질문 <내용>`** — 🔒 질문·답변이 **나에게만** 보임. 예: `/해커톤질문 sjf 트랙 심사기준이 뭐예요?`
- **`/해커톤주제`** — 🔒 답할 수 있는 주제를 카테고리별로 정리해서 목록으로 보여줌
- **`/해커톤도움`** — 🔒 사용법 안내
- **`/해커톤통계`** — 🔒 (서버 관리 권한자만) 총 질문 수·인기 주제 등 사용 통계
- **`!리로드`** — faq.md 수정 후 다시 불러오기 (서버 관리 권한 필요, 유일하게 남은 `!` 명령)

기본값은 **24시간 개방**입니다. 특정 시간에만 받고 싶으면 `.env`의 `QA_START_HOUR`/`QA_END_HOUR`를 조정하세요. 그 외 시간엔 "운영시간이 아니에요"라고만 안내합니다.

### 질문 채널 제한하기

기본값은 **제한 없음** — 봇이 볼 수 있는 채널이면 어디서든 동작합니다. 답변이 ephemeral이라 채널을 어지럽히지 않기 때문에 그냥 둬도 무방합니다.

특정 채널로 모으고 싶으면 `.env`에 채널 ID를 넣으세요.

```
ALLOWED_CHANNEL_IDS=1234567890123456789
```

여러 개는 쉼표로 구분합니다 (`...=123,456`). 채널 ID는 디스코드 **설정 → 고급 → 개발자 모드**를 켠 뒤 채널 우클릭 → "채널 ID 복사"로 얻습니다. 넣은 뒤 봇을 **재시작**해야 반영됩니다(`.env`는 시작할 때 한 번만 읽습니다).

적용 대상은 **학생용 명령 3개**(`/해커톤질문`·`/해커톤주제`·`/해커톤도움`)입니다. 운영진 명령(`/해커톤통계`, `!리로드`)은 어느 채널에서나 쓸 수 있습니다.

허용 채널 밖에서 쓰면 **갈 곳을 안내**합니다 (본인에게만 보임, 채널엔 안 남음).

```
🔒 여기서는 질문을 받지 않아요.
#해커톤-질문 에서 물어봐 주세요!
```

채널 이름이 아니라 **채널 링크**로 나가므로, 나중에 채널명을 바꿔도 안내가 틀어지지 않습니다.

> 제한을 걸면 **DM에서도 동작하지 않습니다.**

설정이 먹었는지는 시작 로그로 확인합니다.

```
   질문 채널: 1개로 제한 (1234567890123456789)
   질문 채널: 제한 없음 (모든 채널)      ← 안 걸었을 때
```

## 5. 노션 내용 넣는 법 ⭐

`faq.md`를 열어 아래 형식으로 추가하면 끝입니다.

```
## 주제이름 | 키워드1, 키워드2, 키워드3
답변 내용 (노션에서 복사해서 붙여넣기 OK, 여러 줄 가능)
```

- 노션에서 페이지 내용을 복사해 답변 부분에 붙여넣으세요.
  (노션 우측 상단 ⋯ → **Export → Markdown** 으로 내보내면 서식까지 그대로 가져올 수 있어요)
- **키워드는 학생들이 실제로 쓸 법한 단어**로 다양하게 넣을수록 잘 잡힙니다.
  예: `와이파이, wifi, 인터넷, 비번, 비밀번호`
- 수정한 뒤 디스코드에서 `!리로드` 를 입력하면 봇 재시작 없이 바로 반영됩니다.
- **키워드를 고쳤다면 아래를 한 번 돌려보세요.** 새 키워드가 다른 주제의 질문을
  가로채지 않는지 확인해줍니다 (설치할 것 없이 바로 실행됩니다).
  ```bash
  python test_faq_matching.py
  ```

> ⚠️ **범용 키워드를 넣을 때 주의하세요.** `감점`, `제공되나`, `언제`, `신청` 처럼
> 여러 주제에 걸치는 단어를 넣으면 엉뚱한 질문까지 그 항목으로 끌어갑니다.
> 실제로 `감점`을 노코드 항목에 넣었더니 "AI 안 쓰면 감점인가요?"가
> 노코드 답변을 받은 일이 있었습니다.
> 되도록 `노코드감점`, `식사제공` 처럼 **구체적으로** 적어주세요.

**주제가 많아지면** `# 카테고리 이름` (해시 1개)으로 구획을 나눌 수 있습니다. 매칭/답변 내용엔 전혀 영향이 없고, VS Code 아웃라인·미리보기 및 `/해커톤주제` 목록에서 카테고리별로 묶어서 보여주는 용도로만 쓰입니다.

```
# 팀 & 트랙

## 팀 빌딩 | 팀, 팀원, ...
...

## 트랙 선택 | 트랙, ...
...
```

## 6. 사용 통계 확인하기

두 가지 방법 중 편한 대로 쓰세요:

- **디스코드에서**: `/해커톤통계` (서버 관리 권한자만 볼 수 있음)
- **로컬 터미널에서**: 봇을 안 켜도, 같은 폴더에서
  ```bash
  python stats_cli.py
  ```
  총 질문 수, 순 사용자 수, 키워드/LLM/실패 비율, 인기 주제 TOP5를 보여줍니다.

키워드로 못 잡은 질문은 `unanswered.log`에 실제 질문 텍스트로 남습니다 — 이 파일을 보면서 자주 나오는 표현을 `faq.md` 키워드에 추가하면 봇이 점점 똑똑해집니다.

### 누가 물었는지 확인하기

```bash
python stats_cli.py --누가            # 못 잡은 질문 전체 (최근순)
python stats_cli.py --누가 시연영상    # '시연영상'이 들어간 질문만
```

```
2026-08-11 14:23:05  [openai]
  질문   : 시연 영상 100초 맞나요?
  사용자ID: 123456789012345678
```

잘못된 안내를 받은 학생에게 정정 공지를 보내야 할 때처럼, 질문한 사람을 되짚어야 하는 상황에 씁니다. 사용자ID로 사람을 찾으려면 디스코드 **설정 → 고급 → 개발자 모드**를 켜고 서버 멤버 검색창에 ID를 붙여넣으세요.

> **키워드로 바로 답한 질문은 원문이 남지 않습니다.** `stats.log`에 `사용자ID + 주제명`만 기록되므로 "누가 어떤 주제를 물었는지"까지만 알 수 있습니다. 원문이 저장되는 건 키워드가 못 잡아 LLM으로 넘어간 질문뿐입니다.

### 미답변 질문 일일 리포트 (자동)

`unanswered.log`를 매일 직접 열어보는 대신, 봇이 요약해서 보내주게 할 수 있습니다.

```
DIGEST_CHANNEL_ID=1234567890123456789
DIGEST_HOUR=9
```

지정한 채널로 매일 아침 이런 리포트가 갑니다.

```
📊 미답변 질문 리포트 (기준: 08/05 09:00 이후)
총 11건이 키워드로 잡히지 않았어요.

1. "밥 주나요?"  (비슷한 질문 3건)
   ┊ "밥 나오나요?"
   ┊ "혹시 밥 주시나요"
   └ 가까운 항목: 식사

2. "반려동물 데려가도 되나요"
   └ ⚠️ 맞는 항목이 없어요. 새 항목이 필요해 보여요
   └ 키워드 후보: `반려동물데려가`
```

비슷한 질문을 묶어주고, 기존 FAQ 중 어디에 가까운지와 키워드 후보를 제안합니다.
보고 `faq.md`를 고친 뒤 `!리로드` 하면 반영됩니다.

> ⚠️ **반드시 운영진 전용 채널을 지정하세요.** 리포트에 학생 질문 원문이 들어갑니다.

> **키워드를 자동으로 추가하지는 않습니다.** 잘못된 키워드 하나가 엉뚱한 답변을
> 내보내기 시작해도 아무도 모르기 때문입니다. 찾는 일까지만 자동화하고
> 반영 여부는 사람이 판단하는 구조입니다.

터미널에서 바로 볼 수도 있습니다 (최근 24시간):

```bash
python digest.py 24
```

두 로그 파일은 학생 데이터가 담기므로 `.gitignore`에 포함되어 커밋되지 않습니다.

| 파일 | 형식 | 담기는 것 |
|---|---|---|
| `stats.log` | `시각 ⇥ 사용자ID ⇥ 결과` | 모든 질문. 질문 원문은 없고 `hit:주제명` 또는 처리 백엔드만 |
| `unanswered.log` | `시각 ⇥ [처리주체] ⇥ 사용자ID ⇥ 질문 원문` | 키워드가 못 잡은 질문만 |

## 7. 계속 켜두려면 (서버 배포)

봇은 `python bot.py`가 실행 중일 때만 작동합니다. 노트북을 닫으면 봇도 멈춥니다.

- **행사 당일만 쓴다면**: 운영진 노트북에서 그냥 켜두는 게 제일 간단합니다.
- **24시간 돌리려면**: **[deploy/DEPLOY.md](deploy/DEPLOY.md)** 를 따라 오라클 클라우드
  무료 서버에 올리세요. 기한 없이 무료이고, 서버 접속 후 명령 3줄이면 끝납니다.

  ```bash
  git clone https://github.com/tlstkdgus/hackathon-faq-bot.git
  cd hackathon-faq-bot
  bash deploy/setup.sh
  ```

  `deploy/setup.sh`가 파이썬 설치·가상환경·시간대·systemd 등록까지 알아서 처리합니다.
  등록 후에는 봇이 죽어도 자동으로 되살아나고, 서버가 재부팅돼도 자동으로 켜집니다.

- **푸시하면 자동 반영되게 하려면**: `main`에 푸시할 때 GitHub Actions가 서버에서
  `update.sh`를 대신 돌려주도록 설정할 수 있습니다. 시크릿 2~3개만 넣으면 됩니다 —
  [DEPLOY.md의 "GitHub에서 자동 배포"](deploy/DEPLOY.md#7-github에서-자동-배포-선택) 참고.
  설정 전까지는 워크플로가 조용히 건너뛰므로 그냥 둬도 무방합니다.

> **참고**: 이 봇은 디스코드에 websocket으로 상시 연결되므로 Cloudflare Workers,
> AWS Lambda 같은 서버리스에는 올릴 수 없습니다. 24시간 켜져 있는 서버가 필요합니다.
> 대신 외부에서 들어오는 접속을 받지 않으므로 **방화벽 포트를 열 필요는 없습니다.**

## 자주 묻는 문제

- **봇이 아무 반응이 없어요** → MESSAGE CONTENT INTENT를 켰는지, 봇에게 채널 읽기/쓰기 권한이 있는지 확인
- **`/해커톤질문`이 자동완성에 안 떠요** → `applications.commands` 스코프로 재초대했는지, `.env`에 `DISCORD_GUILD_ID`를 넣었는지 확인 (안 넣으면 반영에 최대 1시간)
- **`DISCORD_TOKEN 환경변수가 없습니다`** → 위 3번의 토큰 설정을 다시 확인
- **`pip install` 이 안 먹혀요 (Windows)** → `pip` 대신 `python -m pip install -r requirements.txt` 사용
- **`python --version` 이 버전 없이 `Python` 만 찍고 끝나요 (Windows)** → PATH에 잡힌 게 실제 파이썬이 아니라
  **Microsoft Store 앱 실행 별칭**(`%LOCALAPPDATA%\Microsoft\WindowsApps\python.exe`, 0바이트 스텁)입니다.
  파이썬이 설치돼 있어도 이렇게 보이니 "설치 안 됨"으로 오해하기 쉬워요.
  실제 설치 경로는 `where python` 대신 아래로 확인하고, 그 경로를 직접 쓰거나 PATH 앞에 두세요.
  ```powershell
  # 설치된 파이썬 목록 (uv·공식 설치본 모두 여기에 등록됩니다)
  reg query HKCU\SOFTWARE\Python /s /f InstallPath
  reg query HKLM\SOFTWARE\Python /s /f InstallPath
  ```
  설정 → 앱 → **앱 실행 별칭**에서 python.exe 별칭을 끄면 혼동이 사라집니다.
- **질문을 못 알아들어요** → 해당 주제의 키워드에 그 표현을 추가하고 `!리로드` (또는 `unanswered.log` 확인)
- **`.env`를 고쳤는데 반영이 안 돼요** → 봇을 재시작해야 합니다. `.env`는 시작할 때 한 번만 읽습니다.
  로컬은 `Ctrl+C` 후 `python bot.py`, 서버는 `sudo systemctl restart faq-bot`
- **`faq.md`를 고쳤는데 반영이 안 돼요** → 디스코드에서 `!리로드` (재시작 불필요)
- **지금은 운영시간이 아니라고만 떠요** → 정상 동작입니다. `QA_START_HOUR`/`QA_END_HOUR`로 시간을 조정하세요.
- **엉뚱한 주제로 답해요** → 그 주제에 범용 키워드가 들어가 있을 가능성이 높습니다. 위 5번의 주의사항 참고
- **`OpenAI 모델 '...'을(를) 쓸 수 없습니다`** → 모델명이 바뀐 것입니다. 로그에 사용 가능한 모델 목록이 함께 출력되니 그중 하나를 `OPENAI_MODEL`에 넣으세요
- **`... 백엔드에 answer() 함수가 없습니다`** → 그 엔진 모듈의 답변 함수 이름이 `answer`가 아닙니다. 해당 백엔드는 건너뛰고 나머지로 동작합니다 (위 [LLM 백엔드](#llm-백엔드-전환과-자동-폴백) 참고)

## LLM 백엔드 전환과 자동 폴백

OpenAI와 Claude를 모두 지원합니다. `.env` 두 줄로 결정됩니다.

```
LLM_PROVIDER=openai    # 주 백엔드
LLM_FALLBACK=claude    # 주 백엔드가 실패하면 여기로
```

**폴백을 권장하는 이유**: 행사 당일 한쪽 API에 장애가 나거나, 레이트리밋에
걸리거나, 크레딧이 떨어지면 답변이 멈춥니다. 폴백을 걸어두면 자동으로 다른
백엔드가 이어받습니다. 둘 다 실패해도 봇은 죽지 않고 안내 메시지로 마무리합니다.

시작 로그에 현재 구성이 표시됩니다:

```
✅ 로그인 성공: ... (FAQ 66개 로드, 답변 모드: 키워드 + openai (실패 시 claude 폴백))
```

통계(`/해커톤통계`)에는 **실제로 답한** 백엔드가 기록되므로, 폴백이 얼마나
동작했는지도 나중에 확인할 수 있습니다.

> **답변 규칙(프롬프트)은 `llm.py`에 한 벌만 있습니다.** 예전에는 두 엔진 파일에
> 똑같이 복사돼 있었는데, 한쪽만 고치면 어느 백엔드가 답했느냐에 따라 말투가
> 조용히 갈라집니다. 학생은 어느 쪽이 답했는지 알 수 없으니 한곳에서 관리합니다.

**비용은 얼마나 드나요** — 키워드로 잡히는 질문은 API를 아예 부르지 않습니다.
LLM으로 넘어가는 질문만 과금되고, `gpt-5.6-luna` 기준 **1,000건에 약 1,000~5,000원**입니다.
(FAQ 자료가 매번 앞에 붙지만 내용이 동일해서 프롬프트 캐싱이 걸립니다)

**또 다른 LLM을 붙이려면** `claude_engine.py`와 같은 인터페이스
(`is_enabled()`, `answer(question, entries)`)로 모듈을 만들고 `llm.py`의
`_load()`에 한 줄 추가하면 됩니다. `bot.py`, `faq_engine.py`는 손댈 필요 없습니다.

⚠️ **함수 이름은 반드시 `answer`여야 합니다.** `llm.py`가 백엔드를 구분하지 않고
`eng.answer(...)`로 부르기 때문입니다. 이름이 다르면 그 백엔드는 체인에서 제외되고
시작 로그에 `answer() 함수가 없습니다` 경고가 찍힙니다.

## 매칭이 어떻게 동작하나

`faq_engine.find_answer()`가 항목별로 점수를 매겨 가장 높은 것을 고릅니다.

- 키워드가 질문에 그대로 있으면 만점, 오타·변형은 유사도 0.82 이상일 때만 인정
- 점수는 **키워드 길이로 가중**됩니다. `와이파이`(4자)가 `팀`(1자)보다 크게 기여해요
- 총점이 `MIN_SCORE`(1.0) 미만이면 매칭 실패로 보고 LLM에 넘깁니다
- 동점이면 (맞은 키워드 수 → 가장 긴 키워드 → 제목) 순으로 판정합니다.
  **항목 순서에 영향받지 않습니다** — `faq.md`에서 위치를 옮겨도 답이 바뀌지 않아요
- 1·2위가 모든 지표에서 완전히 같으면 키워드로는 판단이 불가능한 질문이므로,
  찍지 않고 LLM에 넘깁니다 (LLM은 FAQ 전체를 보고 고르니 더 정확합니다)

오답이 잦으면 `MIN_SCORE`를 높이고(→ LLM 호출 증가), 너무 자주 LLM으로
넘어가면 낮추세요. `faq_engine.py` 상단에 있습니다.
